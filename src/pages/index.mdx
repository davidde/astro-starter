<h1 class='gradient-text text-[2.6em]'>Welcome to this Astro Starter!</h1>

This starter is a batteries-included starting point for anyone looking
to build a website with [Astro](https://astro.build/), [Typescript](https://www.typescriptlang.org/) and [TailwindCSS](https://tailwindcss.com/).

It comes with a few integrations, plugins and fonts already configured in the `astro.config.mjs` file. You can customize this setup with [Astro Integrations](https://astro.build/integrations) to add tools like React, Vue or Solid to this project.

Here are some ideas to get started with this template:

- Edit this page in `src/pages/index.mdx`
- Check out the included blog posts in `src/content/blog/`
- Customize the blog post page layout in `src/layouts/PostLayout.astro`

Have fun! If you get stuck, remember to read the [Astro docs](https://docs.astro.build/) or join the [Astro Discord](https://astro.build/chat) to ask questions.

Looking for themes? Check out [all Astro themes](https://astro.build/themes/).
